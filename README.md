# My Portfolio

Portfólio pessoal estático para o desenvolvedor Fábio Gutemberg.

## Descrição

Projeto simples em HTML, CSS e JavaScript que apresenta:
- seção About com perfil e botões de ação
- seção Experience com cards de habilidades
- seção Projects com cards de projetos recentes
- navegação fixa com rolagem suave
- efeito de fundo em grade e menu mobile

## Estrutura do projeto

- `index.html` — página principal
- `css/styles.css` — estilos e layout responsivo
- `js/scripts.js` — interações do menu e animação de fundo
- `assets/img/` — imagens usadas no portfólio
- `LICENSE` — licença do projeto

## Como usar

1. Abra `index.html` no navegador.
2. Ou hospede em um servidor estático (por exemplo, GitHub Pages, Netlify ou Vercel).

## Personalização

- Atualize o texto em `index.html` para seu nome, cargo e descrições.
- Substitua as imagens em `assets/img/` para usar fotos e ilustrações próprias.
- Ajuste as cores e tipografia em `css/styles.css`.
- Configure links de redes sociais e GitHub nos ícones e no botão "Visit GitHub".

## Observações

- Não há dependências externas instaláveis; o projeto roda diretamente no navegador.
- A fonte usada é `Poppins` carregada via Google Fonts.
- A biblioteca `Font Awesome` é usada para ícones.
